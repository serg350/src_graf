## Предлагаемая новая архитектура

### ✔️ Вынести фронтенд в отдельный модуль

```
/frontend
  /components
    GraphView.jsx
    HistoryPanel.jsx
    SubgraphModal.jsx
  /services
    api.js
  /utils
    graph_parser.js
```

## Предпологаемая схема архитектуры

```
Django (Backend)                      Frontend (React/JS)
--------------------------------------------------------------
/api/graph/<id> -> JSON -------→     загрузка и визуализация графа
/api/events/<session> -> SSE ----→   анимация переходов
/api/start_execution ----------→     запуск выполнения

                                    Подсветка, zoom, история,
                                    модальные окна подграфов,
                                    кастомный UI.
```

## Ожидаемые результаты

* Интерфейс станет **в разы проще** поддерживать.
* Система станет визуально современной.
* Добавление новых функций станет значительно проще.
* Backend остаётся чистым административным, а фронтенд берёт на себя визуализацию.
