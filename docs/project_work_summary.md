# Краткое описание выполненных и планируемых работ

## Что сделано

- Разработана серверная часть для хранения и обработки графовых моделей на базе Django.
- Реализован импорт графов из файлов `.dot` и `.adot`.
- Добавлена поддержка загрузки и обработки связанных входных параметров из `.aini`.
- Реализовано сохранение графов, состояний, переходов и вложенных подграфов в базе данных.
- Подготовлены API-методы для получения списка графов, структуры конкретного графа и полной структуры с подграфами.
- Реализована интерактивная веб-визуализация графов на отдельном React-фронтенде.
- Добавлена поддержка отображения вложенных подграфов и перехода к их детализации.
- Реализованы настройка направления раскладки графа и переключение отображения подграфов.
- Реализован запуск обхода графа из веб-интерфейса.
- Добавлена форма подготовки запуска на основе параметров из `.aini`.
- Реализована передача начальных данных в задачу исполнения.
- Добавлен поток событий выполнения для отображения текущего состояния обхода.
- Реализована подсветка активных узлов и переходов во время исполнения.
- Добавлено сохранение истории запусков и событий исполнения.
- Реализована панель истории запусков для просмотра предыдущих обходов.

## Над чем работаю сейчас

- Убираю искусственную задержку исполнения, которая использовалась только для демонстрации визуализации.
- Перенощу демонстрационное замедление из ядра исполнения в интерфейс, чтобы реальные вычисления не искажались.
- Продумываю переход от SSE к WebSocket для более гибкого обмена событиями между сервером и клиентом.
- Продумываю реализацию разных стратегий исполнения: последовательную, локально-параллельную и удалённую.
- Продумываю возможность подключения внешних вычислительных модулей, включая C++-компоненты для ресурсоёмких расчётов.

- Необходимо подумать над новым параметром для узлов и переходов, чтобы можно было определить каким образом будет происходить математика Pytohn, интерпритатор C++ внутри Python, чистый переход на C++ (Или вообще стоит отказаться от математики на Python?)
