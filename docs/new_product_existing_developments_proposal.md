# Предложение по учету существующих разработок в новом продукте

## 1. Предлагаемая целевая архитектура

Предлагаю разрабатываемую систему разделить на пять логических сервисов.

### 1.1. Сервис графовой модели

Назначение: формальное представление вычислительного метода в виде масштабируемой графовой модели.

Должен включать:

- внутреннее представление графа;
- описание узлов, переходов, подграфов, циклов и ветвлений;
- описание входных и выходных данных;
- аннотации возможных исполнителей;
- оценку вычислительной стоимости узлов;
- оценку стоимости передачи данных между узлами.

### 1.2. Сервис планировщика

Назначение: преобразование графовой модели в план выполнения.

Должен включать:

- поиск независимых по данным подзадач;
- формирование очереди задач;
- выбор исполнителя для узла или подграфа;
- учет числа ядер, памяти, доступного ПО и типа вычислителя;
- минимизацию межузловых коммуникаций;
- динамическое перепланирование при неравномерной нагрузке;
- механизмы отмены, повторного запуска и обработки ошибок.

### 1.3. Сервис исполнения

Назначение: фактическое выполнение задач, подготовленных планировщиком.

Должен поддерживать несколько режимов:

- последовательный режим;
- локальный параллельный режим;
- удаленное исполнение на вычислительных узлах;
- гибридное исполнение;
- подключение Python-функций;
- подключение C++-компонентов для ресурсоемких расчетов;

### 1.4. Сервис событий, метрик и истории

Назначение: сделать вычислительный процесс наблюдаемым, воспроизводимым и пригодным для анализа.

Должен фиксировать:

- старт и завершение запуска;
- старт и завершение узла;
- старт и завершение ветви;
- ожидание зависимостей;
- передачу данных;
- назначение задачи на исполнитель;
- ошибки;
- повторные попытки;
- время выполнения;
- объем переданных данных;
- загрузку исполнителей;
- простой ресурсов;
- итоговые показатели ускорения и эффективности.

### 1.5. Сервис визуализации и аналитики

Назначение: использовать GraphVisLab как интерфейс исследования, демонстрации и анализа.

Должен обеспечивать:

- просмотр графовой модели;
- просмотр подграфов;
- live-отображение исполнения;
- replay завершенного запуска;
- отображение узких мест;
- отображение распределения задач по исполнителям;
- экспорт результатов эксперимента для отчетов и статей.
